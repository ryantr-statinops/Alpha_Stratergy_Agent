# Parameter Syntax — Compatibility Index

Parameter guidance is mode-specific:

- [`time_series/parameters.md`](time_series/parameters.md) — indicator periods, rolling windows, entry/exit thresholds, and long-only sizing.
- [`cross_sectional/parameters.md`](cross_sectional/parameters.md) — rank, winsorization, eligibility, factor combination, and portfolio construction.

API runtime defaults belong to the applicable feature or operation catalog. Research parameters belong to these mode-specific guides and must be preregistered in each experiment manifest.
