# Research Governance

Mode-independent research and validation contracts.

| Document | Purpose |
|---|---|
| [`validation_protocol.md`](validation_protocol.md) | Preregistration, Train/Validation/Test, locked OOS, and decisions |
| [`experiment_manifest_schema.md`](experiment_manifest_schema.md) | Family/variant metadata, trial count, and test-access audit |

These documents govern experiments outside the XNOQuant strategy sandbox. Strategy code executes a frozen signal; it does not create data splits or decide whether an alpha is validated.
